Minnow 0.1.6 adds an MCP hub for connecting external agents and a clearer view of token usage.

## Highlights

- **MCP hub** — Connect an external agent to Minnow's Issues, Brain, and user manual through HTTP or a local command. Choose read-only or read-and-write access and copy the configuration from Settings → Integrations.
- **Usage timeline** — Explore token use over time in Settings, with time-range controls and a breakdown of prompt and completion tokens.
- **Reliability** — MCP discovery handles failed connections more gracefully, and Orchestrate restores a builder's worktree snapshot without merging newer integration changes into it.

## Downloads

- **Windows:** `Minnow-Setup-0.1.6.exe`
- **Linux:** `Minnow-0.1.6-x86_64.AppImage` (make it executable with `chmod +x` before running)
- **macOS:** build to be added separately.

This release remains a draft while the macOS package is prepared. Draft releases do not appear in the in-app updater.
