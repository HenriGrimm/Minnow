# Minnow 0.2.2

Minnow 0.2.2 adds External Connections for the CLIs your agents deploy with, makes agent questions sturdier, and introduces the new pixel minnow logo.

## Highlights

- **External Connections.** A new Settings section brings GitHub, Fly.io, Supabase, and Clerk setup together. Minnow checks each CLI in your workspace shell, shows whether it is installed and signed in, and opens a sign-in terminal or install guide when something is missing.
- **Service skills.** New built-in `/fly-cli`, `/supabase-cli`, and `/clerk-cli` skills teach agents to work through those signed-in CLIs.
- **New logo.** The fish mark is replaced by a pixel minnow across the app, installers, tray, and favicon. The boot screen now fills the mark in column by column, and stays still under reduced motion.

## Agent questions and requests

- Questions from agents are validated before they are shown, so a malformed question returns a clear error to the agent instead of a broken card.
- Question cards show the agent's own title, and a saved question that can no longer be opened can be dismissed.
- Question notifications no longer pop up when the question is already visible in the chat you are looking at.
- Pending requests from chats started in another host point you back to that host.

## Fixes

- **Windows CLI updates.** Codex and Claude Code installed through npm now update without file-in-use failures. Failed updates explain whether the cause was the network, a locked install, or a timeout.
- **Private sign-in terminals.** Terminals opened for interactive sign-in do not record commands in Minnow's terminal history.
- **Claude reasoning.** Claude Code reasoning now displays as full reasoning rather than as a summary.
