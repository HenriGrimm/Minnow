Minnow 0.1.10 adds plugin apps and UI extensions, account usage for Codex and Claude, and more reliable CLI conversations. It also makes board failures easier to investigate, brings missing GitHub issues into Sync all, preserves composer drafts while browsing prompt history, and fixes update restart hangs.

## Highlights

- **Extend the workspace with plugins.** Plugins can now add apps, menus, command palette actions, direct slash commands, and UI beside chat metrics. Install or enable an extension and its UI loads without restarting Minnow.
- **See your account allowance.** Codex and Claude subscription usage appears in Models → CLIs and beside the chat model, with remaining percentages, reset times, and refresh controls.
- **Keep Claude conversations intact.** Screenshot results stay in the current native conversation, and verified tool-handoff checkpoints improve recovery after interruptions.
- **Understand failed board runs.** Integration failures show the recorded check, exit code, command output, and expandable evidence directly in the report.
- **Recover your unsent draft.** Prompt history restores your draft, selection, and scroll position; Alt+Up/Down explicitly browses history from long or multiline text.

## All changes since 0.1.9

### Plugins

- Added trusted frontend modules to API v1 plugin packages, including UI-only packages. Extensions load at startup and reload when packages are installed, updated, reloaded, enabled, disabled, or removed.
- Added plugin apps to the app rail, app command palette, and hash routing, with namespaced identities, remembered app preferences, and cleanup when an extension unloads. Plugin apps open in the main window.
- Added menu contributions, a **Plugin commands** menubar menu, command palette actions, and custom menus using Minnow's shared menu renderer.
- Added direct plugin slash commands to the composer picker, with namespaced commands and optional aliases that cannot replace existing commands or skills. These actions can run while a reply is streaming and do not require model generation; command errors preserve the input for correction.
- Added managed DOM mounting and stable slots for the menubar, throughput indicators, and message metrics. Managed mounts follow replaced UI elements and dispose their subscriptions when removed.
- Added chat and workspace usage APIs for plugin token counters, including completed-request totals, cost, and live or last metrics. Usage snapshots exclude message text and credentials and remain scoped to the current workspace.
- Added a **chat token counter** example plugin with a counter beside throughput, a usage app, and menu and command palette actions. Updated the plugin manual and `/build-plugin` authoring guidance.
- Settings now identifies trusted UI entries and displays UI load errors. Installation explains that frontend modules run in the host document with DOM and authenticated API access; failed activation rolls back managed contributions.

### Account usage and agent CLIs

- Added Codex and Claude subscription allowance displays in **Models → CLIs** and a **Usage** button beside the Code chat model. The button shows the remaining percentage for the most-used quota window.
- Added quota-window details, reset times, last-refresh information, automatic refresh while visible, and manual refresh with provider retry handling. Failed refreshes mark retained measurements as **last-known usage**; missing limits show as unavailable.
- Account usage includes activity outside Minnow and is separate from chat token totals. Checks do not generate a model response. Codex requires a ChatGPT login and Claude requires a subscription OAuth login; API configurations do not report subscription quota.
- Enabled Minnow tool calls for Codex models that require code mode. Tool descriptions retain the original Minnow tool names, and newer Codex native environment and delegation features stay disabled so calls use Minnow's shared tool runner.
- Preserved Claude's native session when screenshot images arrive through tool results, avoiding a process restart and replay of the growing conversation.
- Added verified Claude checkpoints at tool handoffs. After an interruption, matching saved conversations can resume once all pending tool results are recorded; mismatched history or configuration rebuilds from Minnow history without executing recorded tools again.
- Kept CLI tool catalogs stable throughout a turn by supplying the full permitted catalog from the outset. Clarified Claude's advertised MCP tool names in its instructions.
- Preserved Claude text, reasoning, and final usage that arrive after the first tool call. Added native rate-limit observations, resolved model aliases, and recovery reasons to CLI diagnostics, with complete usage across continuations.
- Fixed CLI output visibility when switching to alternate Code views, including the Brain map, and restored it when returning to chat.

### Issues and workspaces

- **Sync all** now discovers missing open and closed GitHub issues before pushing unlinked cards and syncing linked issues. Imports go into Triage, retain remote metadata, avoid duplicate imports and redundant pushes, and run before parent-first synchronization.
- Discovery follows the selected workspace scope. **All workspaces** includes the current workspace and other workspaces represented by local issues; automatic linked-only sync keeps its existing scope. Discovery uses the existing limit of 500 GitHub issues per workspace.
- Improved issue detail layout with wrapping editable titles, labelled Type/Status/Priority controls, and a tidier labels and workflow footer. Fixed empty description placeholders overlapping focused editing.
- Added hierarchy connector lines for nested child issues in the issue list.
- Run-target controls now show the current workspace by name in both the chat composer and Issues → Send to chat.

### Orchestrate boards

- Integration failure reports now show a meaningful headline from the recorded evidence, including the failed check and exit code when available. Command output appears in a bounded, keyboard-scrollable disclosure, with remaining structured evidence under **Check details**.
- Attempt blocker summaries now keep every blocker expandable instead of truncating the list. Restored collapsible task rows and aligned Runs and Files in a consistent two-column layout.
- Task-detail conversations always use the full transcript view. Activity stays in the reading flow, thoughts start expanded, tool results start closed, and individual disclosure choices survive live updates.
- Fixed board transcript tool rendering to retain code changes and attachments, and to avoid showing an empty result for a tool that is still pending. Patch tool summaries now show the affected file or file count and whether the patch was applied.
- Preserved round usage, runtime, and CLI diagnostics in attempt transcripts. Rejected builder and tester reports now return the complete required argument schema in the first error, reducing retries for missing fields while retaining validation.

### Composer and recovery

- Prompt history now preserves unsent text, caret selection, and scroll position. Returning from history restores the draft, and edits to recalled entries survive navigation between entries.
- Browsing history no longer overwrites the unsent draft on blur, chat switching, or session save. Pressing Down at the draft tail leaves it intact.
- Plain Up/Down recalls history only at the edges of a single-line composer. Added **Alt+Up/Down** for explicit recall from anywhere, including wrapped and multiline prompts.
- Restored composer scrolling after clears, exposed native scrollbars, and aligned skill highlighting with the visible text width.
- **Continue** on a failed turn now clears stale failure banners, markers, and recovery controls while retaining partial output and tool results. A subsequent failure displays its own notice.

### Startup, updates, and maintenance

- Added startup recovery controls that work even when the application module fails to load. Failed startup offers **Reload Minnow**, and stalled startup offers retry controls without prematurely marking the workspace ready.
- Kept the paired-device connection screen visible during startup and preserved the saved device credential when retrying a connection.
- Fixed update restart hangs caused by upgraded WebSocket connections keeping the packaged server open. Shutdown now closes those connections before installing the downloaded update; Windows updates apply silently and relaunch Minnow.
- Added optional native-call crash breadcrumbs through `MINNOW_NATIVE_CRASH_TRACE=1`, recording operation status and caller stacks without argument or result contents.
- Expanded regression coverage and local smoke tools for account usage, plugin UI, startup recovery, update shutdown, Codex tool calls, Claude screenshot and interruption recovery, board transcripts and reports, GitHub imports, and composer history. Removed the unused issue hierarchy QA fixture.
- Added a detailed context-compression guide and updated the shipped manual, technical reference, product wiki entries, keyboard shortcuts, and archived 0.1.9 release notes.

## Downloads and updates

Packages are included for Windows, Linux x86_64, and Apple Silicon macOS. Installed users can check for published releases under **Settings → About & troubleshooting → Updates**.
