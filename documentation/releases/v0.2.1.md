# Minnow 0.2.1

Minnow 0.2.1 introduces the Graphite workspace, improves setup and model connections, and adds safer chat history controls.

## Highlights

- **Graphite workspace.** Updated app chrome, bundled fonts, appearance controls, shared file and browser tabs, split workbench panels, and side and bottom panels. Legacy Dashboard links now open Code chat.
- **Simpler setup.** Test provider connections before saving, clearer subscription connections, and managed CLI installation on macOS.
- **Chat history controls.** Edit, replay, and delete supported server-owned chat history, with recovery for interrupted work.
- **Unified updates.** Manage Minnow and CLI updates through a shared update center.

## Workflow improvements

- Check out open GitHub pull requests from the branch picker, including fork PRs, while preserving dirty-file consent.
- Access the file pane at every permission level while retaining workspace boundary checks.
- Improved thread search, task visibility, checkout and dev-server views, Git review, Issues, and workspace navigation.
- Added per-model Fast mode controls for Codex and Claude Code.
- Phone Threads now separate Active and Archive views, alongside refreshed mobile layouts.

## Reliability and interaction

- Permission changes are acknowledged by the server before being presented as saved; ordinary chats refresh their permission level at each turn.
- Denied tool calls return recoverable errors to the agent instead of ending the turn.
- Pending approvals and recovery controls sit beside the composer, with settled requests returning to the transcript.
- Improved startup responsiveness, context-document read deadlines, file-tree polling, editor accessibility, diff states, and chat archive responsiveness.
- Unified prompt composition across desktop, server-managed, and headless chats.
- Aligned app headers and window controls, and improved handling of wide transcript content.
