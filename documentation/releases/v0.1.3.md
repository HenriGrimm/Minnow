# Minnow v0.1.3 — Open beta

Seventh open-beta build. Focused on a **dedicated Source Control app**, **Compact and Full chat transcript views**, **context usage visibility**, **default model configuration**, and **release gating** for Super Plan and Research while those surfaces finish hardening. Feedback and bug reports are welcome on [GitHub Issues](https://github.com/HenriGrimm/Minnow/issues).

19 commits since [v0.1.2](https://github.com/HenriGrimm/Minnow/releases/tag/v0.1.2) (10 Sep 2026 → 11 Sep 2026). Full diff: https://github.com/HenriGrimm/Minnow/compare/v0.1.2...v0.1.3

## Highlights

- **Source Control app** — A released core app on the navigation rail at `#/app/source-control`. Review changes, history, branches, stashes, worktrees, pull requests, and CI in a full view that leaves the Code chat transcript intact.
- **Compact and Full chat views (#1194)** — Settings → Appearance → Chat view picks **Compact** (default) or **Full**. Compact groups per-turn activity behind Working/Worked disclosures and shows per-turn edited-file summaries with inline diff review; Full keeps every transcript row visible.
- **Context usage tracking** — Richer context ring and usage metrics, improved web content extraction for context budgeting, and UI polish across the composer stats strip.
- **Default model configuration** — Centralized default-model binding management so new chats and the menubar chip resolve the intended provider/model pair consistently.
- **Release gating** — **Super Plan** and **Research** are hidden for this release (`SUPER_PLAN_ENABLED = false`, Research `releaseState: 'hidden'`). Planning stays in Plan mode; deep research stays off the rail until those surfaces are ready.

## Install (Windows)

1. Download **Minnow-Setup-0.1.3.exe** from the [v0.1.3 release assets](https://github.com/HenriGrimm/Minnow/releases/tag/v0.1.3) (attached when the draft is published).
2. If SmartScreen warns about an unsigned build, choose **More info** → **Run anyway** (one-time for the first manual install).
3. On first launch, choose a workspace folder, then complete setup or connect a model from **Settings**.

## Install (Linux)

1. Download **Minnow-0.1.3-x86_64.AppImage** from the release assets.
2. Make it executable: `chmod +x Minnow-0.1.3-x86_64.AppImage`
3. Run it (AppImage; no system package manager required). Tray integration needs AppIndicator/StatusNotifier (common on KDE; GNOME may need an extension).

## Install (macOS)

Skipped for this release (same as v0.1.2).

## Updates

Packaged installs check [GitHub Releases](https://github.com/HenriGrimm/Minnow/releases) for `latest.yml` (Windows) or `latest-linux.yml` (Linux AppImage). Attach those feed files when publishing the release or in-app update checks will not see the new build. **Draft** releases are invisible to the updater — publish when all platform binaries and feed files are attached.

## Fixes and changes (since v0.1.2)

### Source Control

- New **Source Control** core app in the dock and app rail; full git surface mounts in `#sourceControlView` without tearing down the active chat.
- Sections for changes, history, branches, stashes, worktrees, pull requests, and CI carry over from the prior Source Control Center overlay, now as a first-class app.
- Documentation, product wiki catalog, and app-preference tests updated for the new app id.

### Chat and context

- **Compact / Full transcript modes (#1194)** — persisted in `appearance.json` as `chatView`. Compact hides intermediate activity behind per-turn disclosures; Full shows every row with tool `<details>` and thoughts collapsed by default.
- Per-turn **edited-file summaries** with lazy inline diff review (`chat-turn-changes.ts` + code-change ledger ranges).
- Context usage ring, composer stats, and web content extraction improvements for more accurate budgeting display.
- `formatCompactCount` / `format-stat-count` now handle trillion-scale token counts.

### Models and settings

- **Default model configuration management** — `default-model` helpers and Settings wiring so the menubar chip, new chats, and provider defaults stay aligned.
- Full-width preview buttons in Settings skill previews; Impeccable skill sync and handling updates.

### Issues

- Refined **closed issue** handling and list/board UI indicators so triage state is clearer at a glance.

### Orchestrate

- Board baseline responses now include **`seq`** for reliable client sync after reconnect.
- Orchestrator reliability fixtures refreshed for regression coverage.

### Release gating and product positioning

- **Super Plan** — server-owned run engine landed on `main` but the mode and Code section are **disabled for release** (`SUPER_PLAN_ENABLED = false`; persisted `super-plan` mode id remaps to Plan). Implementation remains in tree for a future flip.
- **Research** — app set to `releaseState: 'hidden'`; deep-research Settings section omitted while hidden.
- README, PRODUCT.md, hero imagery, and manual copy updated to describe Minnow as a **full agentic development workspace**.
