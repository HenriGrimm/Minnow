Minnow 0.1.11 brings issue tracking into the Code files sidebar, makes sub-agent activity easier to follow, and adds a configurable default folder for new projects. It also introduces interactive Claude sessions behind normal chat, improves Codex reasoning and context display, and fixes issue handoffs, automatic GitHub sync, literal code search, and large Brain graphs.

## Highlights

- **Work on issues without leaving Code.** The files toolbar now has an Issues pane with quick capture, property filters, and the same editable details and actions as the Issues app.
- **Follow delegated work at a glance.** Each sub-agent appears as one timeline step with its brief, status, tool count, duration, and current activity or result.
- **Choose where projects live.** Set a default project folder in Settings, and see that location before creating a project.
- **Keep Claude work moving.** Interactive sessions now power chats, board agents, and enabled helper tasks, with improved startup handling, tool handoffs, and usage accounting.
- **See Codex context accurately.** Reasoning output renders more completely, and the context ring uses native context occupancy rather than per-request billing totals.

## All changes since 0.1.10

### Issues inside Code

- Added an **Issues** ticket button to the files toolbar. It switches the sidebar to the current workspace's issues, grouped by status, with Open, All, and Closed choices and title or ID search. Browsing a worktree retains the Code workspace's issue scope.
- Added property filters for type, status, priority, and project, including **No project**. Filters combine with search and open/closed selection, appear as removable chips, and retain separate selections per workspace while the app is open.
- Added quick capture with **Create** or **Ctrl/Cmd+Enter**: the first line becomes the title and subsequent lines become the description. Drafts survive pane switching and reloads; failed-save retries avoid creating a duplicate issue.
- **Expand** in sidebar quick capture creates the issue, expands it in the background, then clears and refocuses the input so several issues can be recorded in a row.
- Reused the full Issues detail view inside the sidebar, including editable properties, labels, description, links, workflow actions, related issues, and comments. **Back** restores list filters, scroll, and focus; related issues open in the same pane.
- Unified row actions across Code and the Issues app, including viewing, editing in Issues, Send to chat, property changes, expansion, sub-issues, copying, deletion, and opening linked GitHub issues. Context actions are available through right-click, **Shift+F10**, or the row menu.
- Added **Filters** and **New issue** to the blank-space context menu in the Issues list and board, plus New issue in row menus. New issue opens an empty form without copying the clicked issue or column.
- Kept GitHub conflict controls registered independently for each open detail surface, so closing the sidebar detail does not remove conflict handling from the Issues app.

### GitHub sync and issue handoffs

- With **Two-way mirror → Sync automatically** enabled, newly created local issues now create their GitHub counterpart without waiting for a later edit. This includes issues added by agents or received from another window, plus synced-field changes discovered during storage merges.
- Automatic pushes remain scoped to the current workspace. Scratch, other workspaces, initial loads, and recovery loads do not trigger a backfill of older unlinked issues.
- Fixed issue handoffs placing their internal submitted prompt into the composer as an unsent draft. Handoffs now send directly to the created chat, with code references supplied as deduplicated attachments.
- Kept handoff delivery bound to the original chat when you switch chats during worktree setup. Ordinary editable chat seeds still appear promptly in the composer.
- Fixed the issue run-target picker opening in the wrong place when the sidebar rerenders after a mode selection; it stays anchored to the original Send button position.
- Issue tickets in chat now use the available message width.

### Projects and workspace controls

- Added **Settings → General → New projects → Default project folder**. Choose an existing absolute folder, or clear it to restore your home folder's Projects directory. Existing projects are not moved, and the creation form retains its per-project location override.
- The Choose workspace page now displays the effective default location with a **Change default folder** link before project creation.
- **Browse…** saves a selected folder immediately. Typed paths save on blur or Enter, Escape cancels the edit, and save progress and errors appear in an accessible status line.
- Fixed Issues and Preview toolbar buttons appearing active while their pane is collapsed, and kept button state in sync with mobile sidebar opening and closing. Updated Issues and capture controls to use a ticket icon.

### Claude and Codex

- Claude Code now runs an interactive terminal session behind normal chat, requiring **Claude Code 2.1.289 or newer**. Text and images travel through a private connection while Minnow retains tool execution and approval handling.
- Extended interactive Claude sessions to board agents and enabled utility roles, including helpers without a chat ID. One-shot helpers receive native session IDs for hooks and transcript usage accounting, then close and remove their owned native transcript after use.
- Improved first-run Claude setup handling and preserved startup progress and actionable errors in the CLI view. If further setup or sign-in is needed, run `claude` once in Minnow Terminal, complete its prompts, then retry.
- Improved interactive tool handoffs so tools can run before Claude commits its final response. Late text, reasoning summaries, and usage survive generation boundaries and are attributed once; repeated native tool calls are matched without duplicating results.
- Added transcript-based reasoning-summary collection and safer warm follow-ups and recovery. Summary timing follows Claude's native transcript availability; completed native responses supply token counts, and unavailable cost or quota measurements stay unavailable.
- Interactive Claude does not support the legacy CLI dollar-budget flag. A configured cap now produces an actionable request to clear it before interactive inference instead of being silently ignored.
- Fixed Codex reasoning display to retain summary and content deltas, recover text from completed items when needed, and separate sections without repeating streamed output.
- The Codex context ring now prefers native context occupancy and the native window, retaining them through tool handoffs and reloads. Provider/model or history mismatches, clearing, and compaction invalidate that measurement; billing totals remain separate.

### Sub-agents, search, and Brain

- Redesigned sub-agent cards as single timeline steps, replacing duplicate spawn rows. Each step shows the agent, brief, status, tool-call count, and completed-run duration, with one detail line for live activity, an error, or a result headline.
- Kept parallel spawn cards visible after their tool batch in spawn order, instead of hiding them inside a collapsed batch. Removed the continuous status pulse to reduce rendering overhead during long runs.
- Fixed literal code searches containing punctuation, backslashes, or leading dashes. Fixed-string searches now preserve the original snippet, and queries beginning with a dash are treated as patterns rather than command flags. Regular expression search remains available.
- Fixed Brain graph truncation dropping every tag when the node limit was exceeded. Limited graphs retain pages alongside their tags and surviving edges, with the hidden count based on the actual removed nodes.

### Design reference and maintenance

- Replaced the placeholder frontend design reference with comprehensive guidance covering creative direction, layout, typography, color, components, UX copy, responsive behavior, accessibility, motion, performance, and visual verification.
- Included the reference in desktop packages, added package-inclusion and content checks, and corrected recovery advice for a missing reference asset.
- Removed the redundant server-count header from the development server screen.
- Removed stale notes, story and todo artifacts, unsupported QA probes, an old composer snapshot, a CI log, and stray generated TypeScript output. Added ignore patterns and archived the completed repository cleanup plan.
- Added GitHub banner artwork and its regeneration prompt, and updated the shipped manual, technical reference, product wiki entries, regression tests, and local Claude streaming and recovery smoke fixtures.
