## Minnow v0.2.0 is almost here

We're jumping from **0.1.13 to 0.2.0** with simpler agent controls, a more connected issue workflow, and a lot of reliability work.

**What's new**
- **One agent, fewer switches:** use `/ask`, `/plan`, and `/debug` instead of separate composer modes.
- **Simpler permissions:** Manual, Auto, or Full access across tools and integrations.
- **Issues → agent work → review → merge:** linked chats, worktree setup, diffs, and delivery in one workflow.
- **Task-aware model routing:** model pools, quota-aware recovery, and clearer reasoning controls.
- **A dedicated phone interface:** follow live chats, send instructions, and stop work over Wi-Fi or Tailscale.

**What's improved**
Agent completion handoffs, questions, steering, and interruption recovery—plus chat responsiveness, CLI continuity, worktrees, and workspace safety. Saved agent conversations are still there, with better coordination around them.

Windows, Linux, and Apple silicon macOS packages have passed the release build and automated package checks. **The release is still a draft; final interactive smoke testing remains pending.**

Thanks to everyone testing the nightlies and sharing feedback.
