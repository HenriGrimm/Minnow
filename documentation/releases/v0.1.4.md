# Minnow v0.1.4 — Open beta

Eighth open-beta build. Focused on **built-in voice dictation**, **context compaction v2** (server-side context policy, `compact` + `recall_history`, local reasoning replay), a new **Home project overview app**, a **redesigned Models Discover and download flow**, and a **fix for the v0.1.3 packaged-app boot failure**. Feedback and bug reports are welcome on [GitHub Issues](https://github.com/HenriGrimm/Minnow/issues).

38 commits since [v0.1.3](https://github.com/HenriGrimm/Minnow/releases/tag/v0.1.3) (11 Sep 2026 → 15 Sep 2026). Full diff: https://github.com/HenriGrimm/Minnow/compare/v0.1.3...v0.1.4

## Highlights

- **Voice dictation** — Built-in dictation with sensible system speech defaults, so voice input works out of the box without extra configuration.
- **Context compaction v2** — Real server-side context policy with per-turn and per-round compaction, a `compact` command plus `recall_history` for summarization, and improved local reasoning replay with more accurate context token estimation.
- **Home app** — New **Home** project overview app on the rail with AI code activity tracking across your workspace.
- **Models Discover redesign** — The Models Discover and download flow was redesigned end to end, including a new endpoint for fetching creator avatar images.
- **Preview design strip** — The design strip now mirrors with CDP hover picking, so you can point at a live preview and pick the element you want to restyle.
- **Packaged boot fix** — v0.1.3 packaged builds could fail to start with a misleading `fetch failed` (the Impeccable harness registry was missing from `app.asar`). v0.1.4 resolves it, plus the workspace claim transport issue found alongside it.
- **MCP setup simplified** — MCP server setup and OAuth flow simplified.

## Install (Windows)

1. Download **Minnow-Setup-0.1.4.exe** from the [v0.1.4 release assets](https://github.com/HenriGrimm/Minnow/releases/tag/v0.1.4) (attached when the draft is published).
2. If SmartScreen warns about an unsigned build, choose **More info** → **Run anyway** (one-time for the first manual install).
3. On first launch, choose a workspace folder, then complete setup or connect a model from **Settings**.

## Install (Linux)

1. Download **Minnow-0.1.4-x86_64.AppImage** from the release assets.
2. Make it executable: `chmod +x Minnow-0.1.4-x86_64.AppImage`
3. Run it (AppImage; no system package manager required). Tray integration needs AppIndicator/StatusNotifier (common on KDE; GNOME may need an extension).

## Install (macOS)

Skipped for this release (same as v0.1.2 and v0.1.3).

## Updates

Packaged installs check [GitHub Releases](https://github.com/HenriGrimm/Minnow/releases) for `latest.yml` (Windows) or `latest-linux.yml` (Linux AppImage). Attach those feed files when publishing the release or in-app update checks will not see the new build. **Draft** releases are invisible to the updater — publish when all platform binaries and feed files are attached.

## Fixes and changes (since v0.1.3)

### Voice

- Built-in **dictation** with system speech defaults — voice input works out of the box.

### Context and chat

- **Context compaction v2** — server-side context policy with per-turn and per-round compaction, `compact` command and `recall_history` for summarization, and context budget handling improvements.
- **Local reasoning replay** — improved replay of local reasoning for chat templates and more accurate context token estimation (including llama.cpp timings token usage).
- **Adaptive thinking display** — enhanced adaptive thinking display for Anthropic models and improved input handling.
- **Chat work view** — per-turn summary tally and activity line in the chat work view; the turn todo checklist moved from the composer into the transcript.
- **Chat scroll** — layout observer handles late transcript changes so scroll position stays correct.

### Home app

- New **Home** project overview app with AI code activity tracking (rail app; see `documentation/contributor/apps-and-routes.md` for the app registry).

### Models

- **Models Discover and download flow redesigned** — cleaner discovery and download experience.
- New API endpoint for fetching **creator avatar images** for model cards.

### Preview

- **Design strip mirror with CDP hover picking** — point at a live preview to pick the element to restyle.
- Design strip icons are embedded as inline SVG in the native guest, so strip icons render correctly in the packaged app.

### Orchestrator

- Generated commits now use **board task titles** as commit subjects.
- Merge-queue re-sends are tracked and integration repro guidance improved.
- Plan paths included in task seeds.

### MCP

- **MCP server setup and OAuth simplified** — fewer steps to connect an MCP server.

### Brain

- **Tags are the default view** on the knowledge graph.

### Issues

- Quick capture simplified to a minimal popover; commit generation status shown inline.

### Workspace

- Dev checkout stays in **recent workspaces** instead of dropping off the list.

### Electron and packaging

- **Packaged boot fix** — the Impeccable harness registry stays in `app.asar` (the v0.1.3 `fetch failed` boot failure); `validate-packaged-runtime-files.mjs` now refuses extraResources-only leaves so it cannot regress.
- **Workspace claim transport** fix for packaged builds.
- Windows branding differentiates **packaged vs development** builds.

### GitHub CLI and worktrees

- GitHub CLI integration refactored onto a shared `runGh` helper in `forge-ops.js` and `worktree-ops.js`.
- Worktree cleanup inspects husk state before removing stale worktrees.

### Browser and app windows

- Browser navigation allowlist handling and testing enhanced; app window allowlist extended for new applications.

No pull requests merged in this window — all changes landed as direct commits on `main`.
