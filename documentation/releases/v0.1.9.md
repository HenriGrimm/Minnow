Minnow 0.1.9 makes day-to-day development easier to navigate, with a visual Git history, a richer pull request browser, simpler Settings, and conversations that continue across native CLI turns. It also improves mobile access, model configuration, notifications, and recovery when work is interrupted.

## Highlights

- **Explore Git history visually.** Source Control now has a spatial commit map with pan, zoom, a minimap, search, filters, and collapsible history. Switch to a chronological list anytime, and review a selected commit with file tabs and side-by-side diffs.
- **Review pull requests in one place.** Browse PRs by state, search the loaded list, and inspect Overview, Checks, Files, and Commits without leaving Minnow.
- **Spend less time configuring.** Settings has clearer navigation, focused pages, and advanced options tucked away until needed. Settings and Models panels save changes automatically.
- **Keep CLI conversations going.** Claude Code, Cursor Agent, and Codex retain eligible native conversation state between turns, with recovery from Minnow history when a session cannot be resumed.
- **Use the same workspace from your phone.** Paired devices use the full workspace shell and shared composer, with improved startup, reconnection, and layouts for smaller screens.

## All changes since 0.1.8

### Source Control

- Added the Git history map and a remembered Map/List switch. Both views share commit selection, search, filters, collapsed groups, and review actions.
- Added paged history across refs, with branch and remote labels. Loading older commits and refreshing history preserve your position, zoom, and focus; large histories render only the visible scene.
- Added commit review beneath history, with horizontal file tabs and the shared side-by-side diff viewer.
- Redesigned the pull request browser with Open, Merged, Closed, and All filters, search, and current-branch selection.
- Added the PR Overview/Checks/Files/Commits inspector, rendered descriptions, CI links, and review and merge summaries. Refreshes preserve the selected tab, scroll position, and an open new-PR form.
- Consolidated merge-method selection, omitted merge controls for draft PRs, and disabled direct merging for conflicting PRs.

### Settings and setup

- Simplified Settings navigation and reorganized it into six expandable groups: General, Code & workspace, AI & agents, Extensions, Data & privacy, and About & troubleshooting. Each destination opens its own page.
- Moved less-used controls into advanced disclosures. Settings search opens the requested field and its disclosure, and existing section and field links still resolve.
- Separated Skills and Skills Library into their own pages, refreshed agent-pack management, and made settings forms adapt more consistently to narrow, split, and floating panes.
- Redesigned provider connections as cards with provider logos, advanced options, and a Test connection action that checks the saved endpoint without generating a reply.
- Replaced manual Save actions across Settings and Models configuration panels with automatic saving. Rapid edits are combined, and returned settings values are merged without overwriting inputs you are still editing.
- Refreshed first-run setup, including provider connection and default-model selection, and added desktop Interface zoom to the appearance step. Theme and zoom changes apply immediately; zoom is also available in Settings → Appearance.
- Added notification preference resets and a filter for modified preferences.

### Models and agent CLIs

- Added recommended sampler presets for supported DeepSeek R1, Qwen3, Qwen3.5, Qwen3.6, Qwen3.8, Qwen3 Coder Next, and Gemma 4 models. Presets update documented sampling values while preserving output limits and other overrides.
- Added **Unified KV cache** to the Models Load tab. Share the selected context capacity across parallel slots, or allocate the full context per slot; the memory estimate follows the selection.
- Redesigned Models → CLIs as compact expandable rows with installation and authentication status, a provider switch, inline advanced controls, automatic saving, and validation and retry handling.
- Added persistent native conversations for Claude Code, Cursor ACP, and Codex app-server. Each user turn starts a fresh process and resumes eligible saved state; interrupted or mismatched conversations rebuild from Minnow history. Claude's per-process budget resets between turns.
- Improved native CLI lifecycle management, cancellation, cleanup, and session, stream, and usage metadata. Fixed turn-context preservation for seeded conversations with no text input.
- Grouped Cursor effort and Fast variants by model family in the picker. Added per-chat reasoning and Fast controls that select supported advertised variants, including a compact-layout setting.
- Made the reasoning-effort footer menu easier to recognize and restored its native picker behavior.
- Added an explicit inherited-model choice and reset actions for agent model routing, so overrides can return to the current chat model.
- Moved the expanded CLI view's Chat/CLI toggle into its header for easier access.

### Mobile, chat, and accessibility

- Kept paired LAN devices on the full workspace shell and shared composer. The connection screen now waits for authorization and workspace chrome, and connection checks retry after suspension, wake, and network restoration.
- Fixed browser-persisted ID creation on LAN connections for onboarding, issue drafts, model pools, user rules, and plugin channels.
- Improved responsive chat layouts, narrow-pane controls, and touch targets. Mobile viewport handling follows the software keyboard, and composer popovers reposition when the visible viewport changes.
- Improved keyboard focus in mobile drawers and composer popovers, control labels, accessible status announcements, and Markdown link handling.
- Preserved chat scrolling when the composer or surrounding chat panels resize.

### Reliability and performance

- Fixed false save conflicts between chat windows by saving only changed chats after startup and limiting startup repairs to the affected records.
- Routed desktop alerts through Electron's native notification bridge, with click navigation and a notification test action in Settings.
- Improved bulk GitHub issue synchronization with three concurrent workers. Parent issues finish before sub-issues begin, while per-issue locking and safe storage updates remain in place.
- Fixed recovery for stuck Orchestrate boards and cancellation of stale writes.
- Fixed Brain's background code indexer changing the saved workspace when indexing a chat or board worktree. Restarting Minnow now retains the user's project selection.

## Downloads and updates

Packages are included for Windows, Linux x86_64, and Apple Silicon macOS. Once this release is published, installed users can check for it under **Settings → About & troubleshooting → Updates**.
