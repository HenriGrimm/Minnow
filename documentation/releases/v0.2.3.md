# Minnow 0.2.3

Minnow 0.2.3 brings a new Automations hub, customizable input bindings, clearer worktree names, and improvements to source control and chat recovery.

## Highlights

- **Automations.** The Scheduler becomes an Automations hub with running agents, activity, recent runs, and presets including PR Reviewer. Follow a run's conversation live, stop it, or create a custom automation with a plain-language schedule.
- **Custom shortcuts.** Settings now supports keyboard, mouse, wheel, and gamepad bindings, with searchable defaults, recording, and reset controls.
- **Named worktrees.** Worktree titles appear throughout the workspace. New worktrees copy local environments before dependency setup, and stale or locked checkouts have safer recovery paths.
- **Source control.** Refreshed layouts and forms make branch actions, pull requests, workflow inputs, and release actions easier to find. Open a workflow's filtered runs directly from its details.

## Improvements and fixes

- Star a favorite reasoning level for each model. Codex model choices stay available while the CLI is busy or refreshing.
- Models has a dedicated Engine page with llama.cpp controls and MTPLX update guidance.
- Run scripts directly from the Files context menu.
- Issue launches use the shared chat model picker. Saved issues expand in place with Undo, and agents receive clearer guidance for correcting existing issues.
- Follow-up messages survive completed turns and navigation more reliably. Chat launches share work already in progress, and checkout verification limits concurrent work.
- Improved recovery for crashes, hung renderers, retained worktrees, and preview guests.
- Git checkout changes preserve conflict checkpoints and guard against overlapping mutations.
- Desktop updates show clearer progress and release notes.
