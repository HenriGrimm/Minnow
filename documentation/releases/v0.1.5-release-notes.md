Minnow 0.1.5 improves the day-to-day build workflow with a richer Issues view, more capable source control, and better visibility into agent work.

## Highlights

- **Issues projects** — Browse projects and move between issues with improved navigation. Issue mentions in chat now link to their issue, and issue views render more reliably.
- **Source control** — Explore branches as a tree, select multiple branches, and see an inferred parent branch when working with branch trees.
- **Agent CLI** — Improved installation and discovery, Windows PATH resolution, and live reasoning and tool activity in chat.
- **Preview** — Browser history and address-bar suggestions make it easier to revisit pages while building.
- **Models** — Model configuration now lives in the Models app. A per-load vision toggle lets you load a model without its vision projector when needed.
- **Workspace polish** — Collapse the right pane without closing its tabs, drag files from the tree into native apps, and receive desktop notifications with configurable settings.
- **Reliability** — Fixes for runner retries, output-token estimates, issue rendering, and board tester recovery.

## Downloads

- **Windows:** `Minnow-Setup-0.1.5.exe`
- **Linux:** `Minnow-0.1.5-x86_64.AppImage` (make it executable with `chmod +x` before running)
- **macOS:** build to be added separately.

This release remains a draft while the macOS package is prepared. Draft releases do not appear in the in-app updater.
