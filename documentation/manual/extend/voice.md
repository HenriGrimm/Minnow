# Dictate prompts and read replies aloud

1. Select the microphone in the composer, allow microphone access when prompted, and speak. Stop recording and review the transcribed text before sending.
2. A first built-in transcription can take longer while Minnow downloads its Whisper model. Check **Settings → General → Audio** if the wrong microphone is active.
3. To hear a response, open its message actions and select **Read aloud**. Select it again to stop it.

Use **Models → Voice** to choose recognition and speech engines. The built-in recognition runs on your device, and the default read-aloud uses your system voice. Advanced local engines may need the optional worker and a larger model download. If you select an external API, that service receives audio for dictation or the text for read-aloud.
