# Continue a thread on your phone

Keep Minnow running on an awake computer. Start with home Wi-Fi if you only need access nearby. Choose **Anywhere** to connect away from home through Minnow's Tailscale setup.

## Pair the phone

1. On the computer, open **Settings → General → Devices → Connect a phone**.
2. Choose **On my Wi-Fi** or **Anywhere**. For Anywhere, complete the Tailscale sign-in and any approvals shown on the computer.
3. Scan the QR code with the phone and tap **Connect**. Keep the connection sheet open until pairing finishes.
4. Open the workspace and thread on the phone. You can follow the reply, send a message, queue a follow-up, or respond to a request while the host runs the work. Use the phone's surface controls for files, issues, and board details.

Choose **Add Minnow to your Home Screen** if offered. On iOS, use the browser's **Share → Add to Home Screen**. If you switch to an Anywhere address, add it again from that address.

## Reconnect or remove a device

If the phone **Can't reach** the host, make sure Minnow is still running and the computer is awake. On home Wi-Fi, verify both devices are on the same network and the firewall allows Minnow. If the QR expired, make a fresh one. If the microphone is unavailable on a local HTTP address, use the Anywhere HTTPS address.

To revoke access, open **Devices → Your devices** on the computer and choose **Disconnect**. The paired phone uses the host's agent permission level. Disconnect a device you lose.
