# Look up Minnow help or project knowledge

- To learn how to use Minnow, select **Minnow wiki** at the bottom of the workspace sidebar, or use **Open Minnow wiki** in the command palette. Search the manual shipped with your build. You can also ask in chat, “Search the Minnow manual for how to connect to Ollama and cite the page.”
- To retrieve a decision about your own project, open [Brain](../apps/brain.md). Search for the page or ask the agent to read the current version by title. Use Brain's **Edit** view to correct a decision you saved.
- For contribution and release procedures, use the repository documentation or [GitHub Wiki](https://github.com/HenriGrimm/Minnow/wiki).
