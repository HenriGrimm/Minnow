# Find your way around Graphite

Open a workspace from the picker. Code opens the project's threads. If there is no existing thread to resume, **New thread** shows the composer and any issues ready to pick up.

## Find a command or a conversation

- Press **Ctrl+K** / **Cmd+K** outside the editor to open the command palette. Search by task or app name. For example, search **Models**, **Source Control**, **Settings**, **Open boards**, or **Open Minnow wiki**.
- Use **Ctrl+F** / **Cmd+F** outside the editor in Code to search threads, messages, and issues. Open the thread list to switch between conversations in the active workspace. Use **Archive** to find archived threads.
- Select **This thread** in the header or press **Ctrl+.** / **Cmd+.** to check the thread's model, permissions, and checkout before asking it to act.

## Put tools beside or below a thread

Use the **Side panel** or **Bottom panel** button in the thread header. Pick a surface from the launcher. In an occupied panel, select **+** to open the launcher again. The letters shown in the launcher select its entries when the menu has focus.

| Surface | Open it when you need to… |
| --- | --- |
| **Diff** | Inspect changes in the thread's checkout. Use the adjacent **Open workspace diff** action to inspect the main workspace. |
| **Files** | Browse the project's file tree and open files in the editor. |
| **Terminal** | Run commands from the thread's checkout. |
| **Browser** | Open a URL or preview a dev server. |
| **Agents** | Inspect a delegated task and its transcript. |
| **Issue** or **Pull request** | Follow work linked to the thread. The action beside **Issue** opens workspace issues even when the thread has no link. |
| **Side chat** | Ask a read-only question about the open thread in a separate conversation. |

Drag a divider to resize a panel. Right-click a tab to move it to the other panel or close it. To return to the thread at full width, close the side panel with the header button or **Ctrl+J** / **Cmd+J**.

## Open a full app

The sidebar lists **Issues**, **Boards**, **Source control**, **Brain**, and **Automations**. Open **Models**, **Settings**, or the manual from the icons along the bottom of the sidebar. The command palette also opens these destinations. If the sidebar is hidden, select **Show sidebar** next to the workspace header.

Before editing an issue, file, or branch, check the workspace name. A thread can also have its own worktree within that workspace.
