# Find and change a setting

Open **Settings** from the command palette. Search by the control name or what you want to change (Ctrl/Cmd+K focuses the search box). Select a result to open its page; focus moves to the control and it is highlighted. Each page has its own address, so you can bookmark it, reload it, or go back to the previous page.

| You want to… | Search for or open |
| --- | --- |
| Change the theme, tint, text, density, or window zoom | **General → Appearance** |
| Change the tray behavior or rerun setup | **General → Startup and setup** |
| Connect a phone or check updates | **General → Devices** or **Updates** |
| See every keyboard shortcut | **General → Keyboard shortcuts** |
| Change shells, editor settings, or language support | **Code and workspace → Terminal**, **Editor**, or **Language servers** |
| Connect GitHub | **Code and workspace → External connections** |
| Choose what the model sees and how long chats are kept | **AI and agents → Chat context** |
| Change the permission level, prompts, or sub-agent limits | **AI and agents → Agents and permissions** |
| Change rules, tools, or the web search provider | **AI and agents → Rules**, **Tools**, or **Web search** |
| Install an extension or connect MCP | **Extensions → Plugins**, **Skills Library**, or **MCP servers** |
| Check what stays on this computer and what goes online | **Data and privacy → Privacy** |
| Back up your data | **Data and privacy → Backups** |
| See what agents and other devices can reach, or contain agent commands | **Data and privacy → Access** |
| Inspect a failure or copy a report | **System → Health and diagnostics** |

Some rows carry a badge saying when a change takes effect: **Applies now**, **Next message**, **Reopen file**, or **After restart**.

In the sidebar, the arrow keys, Home and End move between pages, and Enter opens a page and moves into it. In a narrow window Settings shows the page list first; pick a page, then use **All settings** to go back.

Open [Models](models.md) to configure providers, model routing, and voice. For tool approvals, use the [composer permission control](../concepts/tools-and-permissions.md).
